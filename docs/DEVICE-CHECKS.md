# Real iPad acceptance checks

This is the single device checklist for Milestones 1–6 and Phase 2. Simulator results remain in
[MILESTONE4_QA.md](MILESTONE4_QA.md) and [MILESTONE5_QA.md](MILESTONE5_QA.md). No device checks have been completed here.

Use an iPad with Apple Pencil. Record the app commit/build, source PDF name and page count, memory observations,
and evidence or failure notes with each run. Fill in every row's model, iPadOS, date, and result (`pass`, `fail`,
or `blocked` with a reason). Use copies of notebooks for interrupted-save, damaged-file, and full-storage checks.
Do not mark device work complete in [PLAN.md](../PLAN.md) until its rows have recorded results.

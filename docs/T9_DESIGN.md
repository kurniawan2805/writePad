# T9 — Page items, format v5

Design settled before implementation (2026-10-25). This note permits Codex to implement T9 following these decisions.

- `PageItem` is a value with UUID, page-local top-left CGRect, and either plain text (font size) or an image asset UUID. Array order is back-to-front. Frames are finite, positive and clamped inside the displayed page, including cropped/rotated PDFs.
- A page's optional `itemsRevision` points to `pages/<pageID>.items-<revision>.json`. Existing v1–v4 pages default to no items. Images live at `images/<assetID>.png`, normalized on import. No blobs in SwiftData.
- Every item mutation creates a new revision. Saves write immutable image assets and item documents before ink → annotations → manifest. A failed manifest write leaves its previous item document intact. Flushes capture the latest items and assets, including changes made during an autosave. Retry uses existing save backoff. Missing/unreadable/undecodable item documents or images stop opening without modifying them: do not silently replace user content. Orphan drawing recovery also reconnects the newest item revision for a recovered new page. Old revisions/assets are retained for backup and undo until the whole package is purged; garbage collection is a future optimization.
- Canvas order is paper/PDF → ink → items, with shared item rendering used for live views, thumbnails and PDF/PNG export. Text is black on transparent paper; images preserve aspect ratio inside their frame.
- Explicit Edit Items mode disables ink gestures. Only item rectangles intercept touches; empty space passes through for scroll/zoom/PDF selection. A one-finger drag moves an item; dragging its bottom-right handle resizes it. Gestures preview locally and commit one undo action on completion; cancelled gestures restore the original. Text editing uses a sheet and commits on Done. Images import from Files or Photos.
- Item undo/redo uses its own UndoManager while Edit Items is active; ink undo keeps the existing canvas manager. Page structure changes clear item history and selection, matching the ink canvas policy. Read-only notebooks render items and refuse mutations/imports.
- Acceptance: v4 load and v5 round trip, text/image mutation and undo/redo, read-only guards, failed-save preservation/retry and flush during autosave, page deletion/reorder, malformed content, PDF/PNG/thumbnail render evidence, UI insertion/edit/move/resize/reopen. Run full iPad simulator suite; Pencil pressure/palm rejection/latency remain real-device checks.
